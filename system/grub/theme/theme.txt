# system/grub/theme/theme.txt — tema de GRUB, mismo lenguaje visual que el
# resto del sistema. Sintaxis verificada contra el manual de GNU GRUB y dos
# temas reales (pop-os/grub-theme, Ste74/Grub2-Theme) — no es CSS, es un DSL
# propio con bloques `+ componente { clave = valor }`.
#
# Deliberadamente sin imágenes: fondo de color plano (--void), nada de PNG
# que generar ni mantener. Es la misma decisión que el greeter — techo
# honesto de lo que se puede hacer sobre una pantalla de arranque, sin
# fingir el liquid glass que no existe aquí.
#
# Las fuentes NO van en este repo como binario: install/stages/60-session.sh
# las genera en la instalación con `grub-mkfont` a partir de
# ttf-jetbrains-mono-nerd (ya en packages/pacman.txt), con -n "Limitless
# Mono" fijo — así el nombre con el que se referencian aquí abajo
# ("Limitless Mono 16", "Limitless Mono 24") es determinista y no depende
# del nombre interno que traiga el .ttf.
#
# Paleta — igual que colors/limitless.lua y starship.toml:
#   #04060d void · #7e93b0 dim · #3b9eff 蒼 azul · #a970ff 茈 morado
#   #ff4a2e 赫 rojo · #46587a gutter/línea
