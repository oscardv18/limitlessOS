# `paru`. Formato idéntico a pacman.txt. install/stages/20-aur.sh instala
# `paru` primero si no existe (es el único punto del instalador que compila
# algo antes de tener un AUR helper).
#
# A diferencia de pacman.txt, un fallo aquí NO detiene el instalador: cada
# paquete AUR es una compilación independiente, y una que falla no debe
# tirar abajo las otras 20. 20-aur.sh continúa y reporta al final.
